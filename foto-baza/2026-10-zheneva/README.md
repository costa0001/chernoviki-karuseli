# Фото-база: Женева, октябрь 2026 (основной образ)

Основной узнаваемый образ Константина сейчас: синий пиджак, очки, красный галстук, значок ceo. Для обложек и личных слайдов берём кадры g*. Одно личное фото на карусель, остальные слайды дизайн.

- g* : синий пиджак + очки (основной образ, использовать)
- x* : без очков (не использовать для узнаваемости)
- s* : семейные (использовать редко)
